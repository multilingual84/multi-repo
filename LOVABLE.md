# Deploy on Lovable

1. Import this project zip/repo into Lovable.
2. Env: VITE_SUPABASE_*, SUPABASE_*, VITE_STRIPE_PUBLISHABLE_KEY, STRIPE_SECRET_KEY, OPENAI_API_KEY (or Lovable AI key if enabled).
3. Domain multi-lingual.tech DNS → host.
4. Tap-to-talk: dual flags (local/tourist), 1 phone turns or 2 phones QR — see TalkPairPanel.

Locales for all UI strings: en, es, zh, de, tl, ja.
